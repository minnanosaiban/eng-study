英語学習

AI で解析する(和訳・区切り・品詞・単語・発音記号・TOEIC・4択)

設定(方法・API キー)

API キーは、この端末のブラウザの中だけに保存します(バックアップ・同期には入りません)。呼び出しは、「解析する」を押したときだけです。

すぐ試す

TOEIC風のオリジナル英文 90文(和訳・区切り・品詞・単語の発音記号・4択つき)を入れます。API は要りません。

英文を貼り付ける

1行に1文。解析(和訳・区切りなど)は、まだ付きません。

ファイルから読み込む

.csv(1列目=英文、2列目=グループ名。「、」で複数)/ .txt(1行=1文)/ .json(バックアップ、または解析済みのデータ。単語も入っていれば、単語も読み込みます)

単語・意味句・IU を登録する

登録済みの英文から、まとめて取り出せます。単語(意味・発音記号・頻出度・例文つき)、意味句(和訳・発音記号つき)、IU(発音記号つき)。難易度とグループは、その英文のものを引き継ぎます。

または、貼り付け。1行に1語。「単語,意味」の形でも書けます。

登録済み

登録の経路のうち、Gemini API・コピペモード・受信箱は、これから作ります。

クラウド同期(暗号化)

学習する英文が選ばれていません。「学習対象選択」で選んでください。
