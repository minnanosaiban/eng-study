# 新アプリ 設計メモ(下書き)

元にしたもの: スプレッドシート「アプリ構成」と、試作(英文構造アナライザー)。
試作は、そのまま残し、新アプリは別に作る。試作で確かめたことは「引き継ぐ」、決まっていないことは「決める」と書く。

## 1. 全体の流れ

```
登録 ──→ 学習対象選択 ──→ 学習 ──→ 記録と復習
(4つの単位を作る)  (どれを学ぶか)  (見る・聞く・解く)  (4つ目。構成表に追加)
```

## 2. 学習の単位(4つ)

| 単位 | 中身 | 区切りの基準 | 試作での扱い |
|---|---|---|---|
| 英文 | 1文 | — | あり(中心) |
| 意味句 | 英文を、意味のまとまりで区切ったもの | 意味(スラッシュリーディング) | 表示のみ(`slash`) |
| イントネーション・ユニット(IU) | 英文を、息継ぎ・音の区切りで区切ったもの | 音 | なし |
| 単語 | 単語・熟語 | — | あり(単語帳) |

「区切りの形」(`phrases`)と「品詞の色分け」(`words`)は、単位ではなく、**英文に付く表示の層**として扱う(§6)。

### 決める:意味句・IU・区切りの形の関係

3つとも、英文を前から区切る。次の2案がある。

- **案A:別々の区切りを持つ** … 意味句・IU・形、それぞれが区切り方を持つ。自由だが、3種類の区切りがずれうる。
- **案B:IU を親にして、意味句は IU の集まり**とする … 区切りが入れ子になり、ずれない。音の区切りと意味の区切りが食い違う文では、無理が出る。

**お勧め:案A**。ただし、どの区切りも「**語の番号の範囲**(何番目から何番目)」で持ち、文字は持たない。試作の samples で、原文とずれない検査ができた方法。

## 3. データの形(表)

1行 = 1つの学習単位。単位ごとに表を分けるが、共通の列を持つ。

**共通の列**: `id`, `type`(英文/意味句/IU/単語), `text`, `ipa`, `ja`(和訳または意味), `level`(難易度), `groups`(グループ), `status`(未学習/学習中/覚えた), `review_count`, `last_reviewed`, `verified`(確認済み)

**単位ごとの列**

| 単位 | 追加の列 |
|---|---|
| 英文 | `words`(語と品詞)、`grammar`、`toeic`、`quiz`、`rel`(関係図)、`illus`(イラスト)、`audio` |
| 意味句 | `parent`(英文の id)、`start`, `end`(語の番号の範囲) |
| IU | `parent`, `start`, `end` |
| 単語 | `pos`(品詞)、`freq`(頻出度)、`src`(用例の英文) |

引き継ぐ決まり:

- 外から届くデータ(AI・受信箱・復元)は、必ず検査してから入れる。形が合わない部分だけを捨て、ほかは残す。
- すでにあるデータには、**足りない項目だけ**を足し、上書きしない。
- 区切りは、語の番号で持ち、つなぐと原文と一致するかを機械で確かめる。

## 4. 分類(「●●で分類」)

分類は、(単位 × 分類軸)の表にする。**難易度は、4つの単位に共通**。

| 単位 | 分類軸の候補(●●を埋める) |
|---|---|
| 英文 | 意味句の数 / 文構造(文型・節の種類) / IU の数 / 単語(含む語) / 品詞(含む品詞) / 難易度 / TOEIC のパート・場面 / 文法項目 |
| 意味句 | 長さ(語数) / 役割(主語・動詞・修飾など) / 品詞のまとまり(名詞句・動詞句ほか) / 難易度 |
| IU | 長さ(語数) / 文中の位置(文頭・文中・文末) / 音の特徴(強勢の数) / 難易度 |
| 単語 | 品詞 / 頻出度 / TOEIC の場面 / 語頭・語尾(接頭辞・接尾辞) / 難易度 |

- 自動でできる分類(語数・位置・品詞・難易度の数値)と、AI が要る分類(場面・文法項目)を分けて、前者を先に作る。
- 試作の自動分類(API 不要)を引き継ぐ。

## 5. 登録

| 経路 | 使う場面 | 試作から |
|---|---|---|
| 都度 Gemini API | 1文ずつ、その場で | 引き継ぐ(`gemini()`、プロンプト) |
| コピペモード | API キー無し | 引き継ぐ |
| 事前に Claude 等 | まとめて | 引き継ぐ(受信箱、検査、`fillMissing`) |

登録する項目(構成表より): 英文・意味句・IU・単語・IPA・和訳・音声・分類各種・関連図・イラスト。

- **IPA**: 単語は、**発音辞書から機械的に作る**(試作の samples で実施。379語が全部通った)。辞書に無い語だけ、手で付ける。AI の IPA は誤りが混じるので、最終案にはしない。
- **決める:英文・IU の IPA** … 語の IPA をつなぐと、弱い発音・音のつながりが出ない。「語の IPA を並べるだけ」と割り切るか、IU ごとに手で付けるか。
- **音声**: 端末の読み上げ(無料)を引き継ぐ。「事前登録」の音声ファイルを作る案は、容量が増えるので、後回し。
- 登録のたびに、**機械で検査**する(区切りの連続性・品詞コード・4択の形・関係図の読み込み)。

## 6. 学習対象選択

どの単位でも、同じ3つの選び方にする。

1. **チェックボックス**:表で選ぶ(並べ替え・絞り込み・全選択)
2. **ランダム**:絞り込んだ範囲から、N件
3. **グループ**:グループを選ぶ

表で見せるのが自然。選んだ結果は「学習セット」として保存し、学習画面は、その並びを順にたどる。

構成表の修正: D26 / D29 / D32 の「チェックボックスで**英文**を選択」は、それぞれ、意味句・IU・単語の誤記と思われる。

## 7. 学習画面

1文を大きく出し、**表示の層**を切り替える。

| 種類 | 選び方 | 項目 |
|---|---|---|
| 英文表示 | **どれか1つ** | 全文 / スラッシュリーディング(意味句) / 区切りごとの形 / 品詞の色分け / 文構造 |
| 音声 | **どれか1つ** | 1回聞く / 区切りごとに聞く / シャドーイング / 聞き取り練習 |
| 補助 | **入り切り** | IPA / 和訳 / 文法 / 単語・熟語 / TOEIC の観点 / TOEIC風4択 |

- 切り替えは、**ボタンとショートカットの両方**。スマホはボタンだけで足りる。
- 設定(どの層を出すか)は覚えておく。
- 「区切りごとに聞く」は、§2 の決定(意味句か IU か)に依存する。IU が入るなら、IU で区切って聞くのが自然。
- 試作から引き継ぐ:音声の設定(声・速さ・繰り返し・間)、プレーヤー、シャドーイングの間、聞き取りの答え合わせ。

## 8. 記録と復習(構成表に無い。追加を勧める)

- 状態(未学習/学習中/覚えた)、復習回数、最終復習日
- 間違いの記録(分類つき)と、弱点の集計
- 4択の結果
- 「覚えた」を除いて復習する

試作を引き継ぐ。**4つの単位すべて**に付ける点が、試作との違い。

## 9. 保存と同期

- 試作は localStorage(約 5MB が上限)。新アプリは、行数が増えるので、**IndexedDB**(端末)+ **D1**(同期)を前提にする。
- 暗号化した同期、QR での接続、受信箱は、設計をそのまま引き継ぐ(鍵は端末の外に出さない)。
- 公開できない英文を含みうるので、リポジトリには入れない。同梱するのは、オリジナルの英文だけ。

## 10. 試作から引き継ぐものの一覧

| 引き継ぐ | 場所 |

| samples の作り方 | 機械で下書き → AI はラベルだけ → 機械で検査 |

## 11. 決めること(まとめ)

1. 意味句・IU・区切りの形の関係(§2、お勧め:案A)
2. 英文・IU の IPA の作り方(§5)
3. 分類軸のうち、最初に作るもの(§4。自動でできるものから)
4. 保存先(§9。IndexedDB + D1 でよいか)
5. 「記録と復習」を最初から入れるか(§8)
6. 最初に作る範囲(例:登録 → 選択 → 学習の英文だけ、を通してから、ほかの単位を足す)
