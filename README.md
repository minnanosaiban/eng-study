# eng-study(仮の名前)

TOEIC 対策の英語学習アプリ。英文・意味句・イントネーション・ユニット・単語を、表のように選んで学びます。

試作: [英文構造アナライザー](https://github.com/minnanosaiban/eng-analyzer)(このアプリの元になった、動く試作)

## 状態

作り始めです。**英文・意味句・IU(イントネーション・ユニット)・単語**の4つの単位で、登録 → 学習対象選択 → 学習を通しました。設計は [docs/design.md](docs/design.md) にあります。

- 登録: サンプル 90 文(API 不要)/ 貼り付け / .csv・.txt・.json
- 学習対象選択: 表で、チェック・ランダム・グループ・絞り込み
- 英文学習: 全文・スラッシュ・区切りの形・品詞の色、IPA・和訳・文法・単語・TOEIC・4択、読み上げ(1回・区切りごと)、ショートカット
- 単語: 英文の「単語・熟語」から取り出す(意味・発音記号・頻出度・難易度・グループ・例文を引き継ぐ)/ 貼り付け(`単語,意味`)/ .json。学習対象選択で、英文と単語を切り替え、同じ形で選べる。単語の学習は、発音記号・意味(隠して、見ると復習1回)・例文・TOEIC、読み上げ(単語・例文)
- 意味句・IU: 英文から取り出す(意味句は和訳つき。どちらも発音記号つき。難易度・グループは英文のものを引き継ぐ)。選択では、語数(1〜2 / 3〜5 / 6以上)と文中の位置(文頭・文中・文末)で絞り込める。学習は、区切りを大きく出し、文の中で見る・文の和訳・読み上げ(区切り・文)。意味句は、和訳を隠して、見ると復習1回。IU は、声に出して練習したら「練習した」で復習1回
- AI で解析: 「登録」の「解析する」で、解析が足りない英文に、和訳・意味句・区切りの形・品詞・IU・単語(発音記号つき)・文法・TOEIC の観点・4択をまとめて付ける。方法は2つ: **Gemini API**(1文ずつ自動。API キーが必要。止められる。エラーで中断)/ **コピペモード**(API キー不要。プロンプトを Gemini に貼り、返事を貼り戻す。5文ずつ)。返事は、原文と一致するかなどの検査を通ったものだけを入れる(通らない部分だけ見送り、ほかは入れる)。入れた英文は「未確認」、単語・意味句・IU の表にも自動で入る。API キーは、この端末の IndexedDB だけに保存し、バックアップに入れない
- クラウド同期(暗号化): 「同期」タブで、パスフレーズから鍵を作り(PBKDF2 60万回)、英文・単語・意味句・IU を AES-GCM で暗号化してから Cloudflare D1 に保存する。サーバーは中身を読めない。2台目は、同期キー(または QR コード)とパスフレーズで接続。変更は数秒後に自動で同期。同じ英文・単語・区切りが両方にあれば1つにまとめる。暗号鍵は、取り出せない形で、この端末の IndexedDB に置く
- 受信箱: 「同期 → 受信箱」で、書き込み専用の合言葉を発行すると、Claude Code などが `tools/inbox-send.mjs` で内容を預けられる(公開鍵で暗号化。復号できるのは、パスフレーズを知る端末だけ)。同期のときに受け取って登録する。状態・復習回数は、外から設定できない。使い方は `CLAUDE.md`
- 音声練習: **シャドーイング**(区切り=IU があれば IU ごとに、聞く → 読み上げと同じ長さの無音で、まねする時間。間は 0.8〜2倍、繰り返しは 1〜3回。終わると復習+1)と、**聞き取り練習**(英文を隠して聞き、書いて、語ごとに答え合わせ。合っていた・聞き取れなかった・書き間違い・余分を色で区別。答え合わせで復習+1)。意味句・IU のカードには「聞いて、まねする」。表示に「IU」も追加
- 記録と復習(「記録」タブ): 学習の状況(単位ごとの 未学習・学習中・覚えた・復習の合計)/ 復習の記録(今日・直近7日・14日・連続日数、14日の棒グラフ。この端末だけで、同期しない)/ **弱点**(間違いの分類ごとの集計。直近7日・30日・全期間。分類を押すと、その英文の一覧と「この分類の英文を復習する」)/ **復習を始める**(覚えた以外から、復習が少ない順に N 件。または、間違えた英文)。間違いは、4択で間違えたとき(分類は問題の論点)・聞き取りで間違えたとき(分類「聞き取り」)に自動で記録し、英文の「間違いの記録」で手動の追加・削除もできる。選択では「間違いあり」で絞り込める。復習は、4択に答える・意味や和訳を見る・シャドーイングを終える・聞き取りの答え合わせ・「練習した」のたびに1回と数える
- 単語の4択(単語のカードの「4択」。AI は使わず、単語の表から機械的に作る): **英語 → 意味** / **意味 → 英語** / **空所に入る語**(例文の中で、その単語を ______ にする。例文にそのまま出てくる単語だけ)。誤答は、ほかの単語から選び、品詞が同じものを先にする。答えるまでは、答えが見えるもの(単語・意味・例文)を隠す。答えると復習+1、間違えると「語彙」で記録(記録タブに「間違えた単語を復習する」)。形は、自動か固定を選べる。samples の329語は、全部で問題を作れる(空所は221語)
- 発音記号を辞書から作る: 「登録」の「発音記号を辞書から付ける」で、発音記号が無い単語・意味句・IU に、発音辞書(CMU Pronouncing Dictionary、アメリカ英語)から付ける。AI の解析を入れるときも、意味句・IU・新しく入る単語の発音記号は、AI ではなく辞書から付ける(辞書に無い語は、AI のものを残す)。単語を貼り付けたときも自動で付く。辞書(`public/dict/cmudict-ipa.txt`、約2.7MB・通信では約0.8MB)は、必要になったとき1回だけ読み込む。`tools/build-pron.mjs` で作り直せる。出典は `public/dict/NOTICE.txt`
- 個別削除: 学習対象選択で、選んだものを「選んだ N 件を削除」/ 学習中のカードの「削除」ボタン。確認のダイアログで、何を消すかを見せる。**英文を消すと、その英文から作った意味句・IU も消える**(単語は、ほかの英文でも使うので残る)。同期している端末からも消える(消した行は、同期で戻らない)。元に戻せない。同じ英文を、受信箱・ファイル・サンプルで、もう一度入れれば、復活する
- **つながり**(聞き取りの練習。英文の画面): 英語は、語と語がくっついて聞こえる(copies of →「コピゾヴ」)。そこを見て・聞いて・書き取る。表示「つながり」(6)は、つながって聞こえやすい語のまとまり(2〜4語)に下線を引き、発音記号を、つながる所を ‿ で出す。「🔗 つながりを聞く」(L)は、そのまとまりを、ゆっくり → ふつうの速さで聞き比べる。聞き取り練習の「つながり部分だけ空欄にする(穴あき)」は、まとまりだけを空欄にして、聞こえた語を書く(答え合わせで、綴りと発音記号を並べて見せる)。**規則で作れるものだけ**(連結 = 子音で終わる語に母音で始まる語が続く / 弱い語 of・to・the などが次の語にくっつく)。辞書(発音辞書)から作るので、AI は使わず、新しく入れた英文にも付く。脱落・はじき音・want to → wanna などは、表せない。読み上げは端末の声なので、つながりの出方は声による
- 英文の見方(「読む」と「聞く」に分けて表示。**全文は、いつも一番上に表示**し、その下に、選んだ見方と、何を基準に区切っているかの説明を出す。選んでいる見方を、もう一度押すと消える(ショートカット: 1 意味・2 文法・3 品詞の色・4 音・5 つながり・0 全部消す)): **読む** = **意味で区切る**(意味のまとまり+日本語訳。スラッシュリーディング)/ **文法で区切る**(文法の単位+形の名前)。**品詞の色**は、見方ではなく**入り切り(☐/☑、ショートカット 4)**で、どの見方にも重ねられる(語の文字色で表し、区切りの下線と重ならない。品詞の情報が無い英文では、色は付かない)。**聞く** = **音で区切る**(一息で読む単位 = IU。シャドーイングの区切り)/ つながり(くっついて聞こえる所)
- 保存: IndexedDB(英文・単語・意味句とIUの表)

まだ無いもの: 脱落・はじき音など、規則が複雑なつながり。文全体での弱い発音や音のつながりを反映した発音記号(語ごとの発音をつないだものです)。

試すには、`public/` を、静的サーバーで開きます(例: `python -m http.server -d public`)。同期・受信箱も試すときは、下の「同期のローカル実行」を使います。Gemini API は、ブラウザから直接呼びます(キーは、この端末の中だけ)。

## フォルダ

```
docs/         設計メモ
public/       アプリ本体(index.html、style.css、js/、vendor/、samples/)
public/dict/     発音辞書(cmudict-ipa.txt。tools/build-pron.mjs で作る)
src/          同期 API・受信箱(Cloudflare Worker。暗号文の保存・取得だけ)
migrations/   D1 のテーブル定義(0001 同期、0002 受信箱)
tools/        inbox-send.mjs(受信箱へ預ける)、build-pron.mjs(発音辞書を作る)
```

## 同期のローカル実行

```bash
npx wrangler d1 migrations apply eng-study-db --local
```

```bash
npx wrangler dev --var SETUP_CODE:localtest
```

## 公開(Cloudflare)

1. `npx wrangler d1 create eng-study-db` で D1 を作り、表示された `database_id` を `wrangler.jsonc` に書く
2. `npx wrangler d1 migrations apply eng-study-db --remote`
3. `npx wrangler secret put SETUP_CODE`(保管庫を作るときのセットアップコード)
4. `npx wrangler deploy`
